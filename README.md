# Лабораторная работа №3

## Описание

Консольное приложение на C# (.NET), реализующее интерактивное меню с четырьмя
режимами работы. Программа демонстрирует базовые приёмы структурного
программирования: разбиение логики на методы, обработку ввода пользователя
через `TryParse`, работу с массивами и замер времени выполнения алгоритмов.

## Функциональность

Главное меню содержит четыре пункта:

1. **Отгадай ответ** — игра, в которой пользователь вводит значения `a` и `b`
   с проверкой допустимых значений (cos(2a) > 0, b > 0), после чего программа
   вычисляет значение функции
   `f(a, b) = (sin(ln_b(5) / √cos(2a)))²`
   с округлением до двух знаков. Пользователю даётся 3 попытки угадать результат.
2. **Об авторе** — выводит ФИО и номер группы.
3. **Сортировка массива** — генерирует случайный массив (от −100 до 100),
   сортирует его двумя алгоритмами (гномья сортировка и сортировка вставками)
   и выводит результаты с замером времени каждого алгоритма в миллисекундах.
4. **Выход** — завершение работы с подтверждением («д» / «н»).

## Стек технологий

- Язык: **C#**
- Платформа: **.NET** (консольное приложение)
- Внешних зависимостей нет — используется только стандартная библиотека
  (`System`, `Math`, `Random`, `DateTime`).

## Установка и запуск

### Требования
- Установленный [.NET SDK](https://dotnet.microsoft.com/download) версии 6.0 или выше.
- Любой терминал / среда разработки (Visual Studio, Rider, VS Code с расширением C#).

### Запуск из терминала

```bash
# из корневой папки проекта
dotnet run
```

### Запуск в Visual Studio
1. Откройте файл решения (`.sln`) или папку проекта.
2. Нажмите **F5** (или **Ctrl+F5** для запуска без отладки).

## Основные методы

| Метод | Назначение |
|---|---|
| `Main` | Главный цикл меню и обработка выбора пользователя |
| `GetIntFromUser` | Универсальный ввод целого числа с проверкой |
| `GetArrayLength` | Ввод длины массива (uint, проверка на число) |
| `CreateArray` | Генерация массива случайных чисел от −100 до 100 |
| `CloneArray` | Копирование массива для честного сравнения алгоритмов |
| `PrintArray` | Вывод массива (только если длина ≤ 10) |
| `GnomeSort` | Гномья сортировка (обмен соседних элементов) |
| `InsertionSort` | Сортировка вставками |
| `SortArrayMenu` | Пункт меню: генерация, клонирование, сортировка, замер времени |
| `PlayGuessGame` | Пункт меню: игра «Отгадай ответ» |
| `GetDoubleWithCondition` | Ввод числа с проверкой дополнительного условия |
| `CalculateFunction` | Вычисление `f(a, b)` |
| `GuessGame` | Логика игры с 3 попытками |
| `ShowAuthor` | Вывод информации об авторе |
| `ExitProgram` | Подтверждение выхода из программы |

## Примечания

- Ввод всех чисел защищён от некорректных данных: при ошибке программа
  просит повторить ввод, не завершаясь аварийно.
- Массив длиной больше 10 не выводится на экран (ограничение читаемости
  консоли) — при этом сортировка всё равно выполняется.
- Время сортировки замеряется через `DateTime.Now` до и после вызова метода;
  для массивов малой длины значения могут оказаться равными нулю.
